        ATLAS ONE

        A production-style reference implementation of a data reliability platform for financial data.

        The problem

        In banks and fintechs, bad data is expensive: a duplicated batch inflates a ledger, a silent schema change breaks a regulatory report, a late partition starves a fraud model. Usually someone downstream finds out first.

        What ATLAS does

        • Detects issues with deterministic checks: freshness, volume, schema contracts, nulls, duplicates, referential integrity, replica reconciliation and distribution drift.
        • Contains them with a lineage-aware quality gate: bad data never reaches gold, consumers keep the last good version.
        • Explains them: root cause, blast radius, owners, runbook and an AI copilot briefing.
        • Recovers: backfills late partitions and tracks MTTD / MTTR.

        Honest scope

        A reference implementation, not a replacement for a production platform. The synthetic sources and SQLite engine keep it runnable anywhere; the design maps 1:1 to S3 + Databricks/Delta + Airflow (see docs/adr).
