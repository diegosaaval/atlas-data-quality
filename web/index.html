      ¿Qué es ATLAS?

      Un monitor de calidad de datos para las tablas que TI carga cada día. No mueve datos: los vigila.

      El problema

      Las áreas de negocio usan tablas que otro equipo carga cada mañana. Cuando una carga llega duplicada, vacía, tarde o con valores imposibles, normalmente alguien se entera tarde: cuando el reporte ya salió mal.

      Qué hace ATLAS cada mañana

      1. ¿Llegó? Vigila la hora acordada de cada tabla y alerta si no aparece.
      2. ¿Llegó completa? Compara el número de registros con lo normal para ese día de la semana.
      3. ¿Está bien? Duplicados, vacíos, rangos, valores permitidos y reglas de negocio (ej. tasa de mora ≥ 0).
      4. ¿Es normal? Detecta valores atípicos con desviación estándar frente al histórico.
      5. ¿Quién lo arregla? Abre un incidente con evidencia, ejemplos y el correo para el equipo responsable. Se cierra solo cuando la siguiente carga está bien.

      Glosario

      Monitor automático
      Control que toda tabla tiene sin configurar nada: disponibilidad, volumen y estructura.
      Regla de calidad
      Condición definida por el negocio que los datos deben cumplir. Cada una se convierte en una consulta SQL.
      Outlier (valor atípico)
      Valor que se aleja más de N desviaciones estándar (σ) de su comportamiento normal.
      Banda de normalidad
      Rango esperado calculado con la mediana y la desviación de los días comparables.
      Puntaje de calidad
      % de controles que pasan, ponderado por severidad (crítica pesa 4, baja pesa 1).
      Incidente
      Un caso por tabla con fallas: agrupa todos sus controles fallidos para no generar ruido.
