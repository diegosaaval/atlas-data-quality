# Roadmap

The local version proves the *behaviour*. Next phases prove it on cloud infrastructure, one layer at a time,
without changing the reliability engine's contracts (`CheckResult`, incidents, lineage).

## Phase 1 — AWS landing zone (Terraform)
- S3 buckets per layer (`landing/`, `bronze/`, `silver/`, `gold/`) with KMS encryption and lifecycle rules.
- IAM roles with least privilege per job; a policy-simulation test in CI (prevents the *permission failure* fault).
- Glue Data Catalog + Athena workgroup; CloudWatch dashboards fed from `/metrics`.
- GitHub Actions with OIDC to AWS (no long-lived keys), `terraform plan` on PRs.

## Phase 2 — Processing on Spark / Databricks
- Port silver to PySpark with Delta Lake `MERGE INTO` (idempotent on `txn_id`), schema enforcement + evolution.
- Gold models as dbt models (dbt-databricks), checks as dbt tests emitting `CheckResult` rows to a metadata table.
- CDC for accounts (Debezium or DMS) instead of snapshot + trickle.

## Phase 3 — Orchestration and lineage
- Airflow DAG mirroring `engine.tick()` tasks; the quality gate as a `ShortCircuitOperator`.
- OpenLineage emitted from Airflow/Spark into Marquez; ATLAS reads lineage instead of `catalog.py`.

## Phase 4 — Fraud / risk ML
- XGBoost model on `gold.fraud_features`, MLflow tracking, SHAP explanations per alert.
- Feature drift monitoring reusing the distribution check; model scoring as a consumer with its own SLO.

## Phase 5 — Product hardening
- OIDC auth, audit log of PII reads, column masking in the warehouse.
- Incident notifications (Slack / Teams webhooks), on-call schedule, post-mortem template generated by the copilot.
